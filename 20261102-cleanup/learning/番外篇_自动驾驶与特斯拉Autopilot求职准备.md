## 零、先说结论（TL;DR）

想进特斯拉 Autopilot（或同级自动驾驶 AI 岗），本质上要成为一个**"会写生产级代码的深度学习工程师 + 懂 3D 几何/多视角视觉的感知研究者"**的复合体。三条硬主线：

1. **工程能力**：Python + **生产级 C++**（这是很多人卡住的地方）、PyTorch 大规模训练、CUDA/部署优化；
2. **算法深度**：检测/分割/BEV 感知/占据网络/端到端驾驶这条现代自动驾驶感知栈；
3. **作品证明**：nuScenes/Waymo 等公开数据集上的项目、开源贡献（comma.ai openpilot / Autoware）、竞赛名次或论文。

**现实提示**（后面第九节展开）：特斯拉 AI 团队几乎全在美国（Palo Alto / Austin），招人极卷、多要 PhD 或强工程履历、还有签证门槛。对国内硕士更**可行**的等价路径是国内自动驾驶公司（小鹏/理想/华为车 BU/Momenta/地平线/文远知行/小马智行/蔚来），**技术栈高度重合**，这份指南同样适用。

## 一、特斯拉 Autopilot 到底在做什么（技术栈全景）

要准备一家公司，先搞懂它的技术路线。特斯拉的路线在自动驾驶界很特殊，值得单独理解：

### 1.1 纯视觉路线（Tesla Vision）
- **砍掉雷达（2021）、砍掉超声波（2022）**，只用 8 个摄像头 → "纯视觉"。这与 Waymo/Cruise 的"激光雷达 + 高精地图"路线**根本对立**。
- 含义：所有 3D 感知（深度、速度、占据）都要**从 2D 图像里学出来**，对神经网络要求极高。这也是为什么特斯拉极度重视数据和大模型。

### 1.2 感知架构演进（面试高频，务必理解）
| 阶段 | 关键技术 | 一句话 |
|------|---------|--------|
| 早期 | 单图 2D 检测 + 后融合 | 每个摄像头各自检测，再手工融合，效果差 |
| **HydraNet** | 多任务共享骨干 | 一个 backbone + 几十个任务头（车道/车辆/行人/交通灯…），省算力、共享特征 |
| **BEV / 向量空间** | 多相机特征 → 鸟瞰图 | 把 8 路相机特征投影到统一的**鸟瞰俯视坐标系**再做感知，天然解决多相机融合 |
| **Occupancy Network** | 3D 占据栅格 | 预测空间每个体素"被占据/空闲 + 语义 + 速度"，不依赖固定类别，能处理未知障碍物 |
| **端到端（FSD v12+，2023-2024）** | "光子进、控制出" | 用神经网络直接从图像输出转向/油门/刹车，大幅减少人工规则代码 |

### 1.3 数据引擎（Data Engine，特斯拉的真正护城河）
- **影子模式（shadow mode）**：车队在后台默默跑模型、对比人类驾驶，自动挖掘"模型出错的场景"。
- **自动标注（auto-labeling）**：用大模型 + 多帧重建离线自动标注，而非纯人工。
- **车队学习**：几百万辆车持续回传难例，形成"发现问题→自动标注→重训→OTA 下发"的闭环。
- 面试会问：你怎么设计一个能自我改进的数据闭环？

### 1.4 基础设施（Infra）
- **Dojo 超算 + 自研 D1 芯片**：为视频训练定制的超算。
- **FSD 车端芯片**：自研推理芯片，强调低功耗高吞吐 → 需要**模型量化/剪枝/部署**知识。

> 📺 **必看**：特斯拉 **AI Day 2021 / 2022** 的完整技术演讲（YouTube）。这两场比任何论文都更直接地讲清了他们的架构（HydraNet、BEV、Occupancy、Data Engine、Planning、Dojo）。看懂这两场，面试的"你了解我们的技术吗"就稳了。前 AI 负责人 **Andrej Karpathy** 的公开演讲也强烈推荐。

## 二、岗位方向（先想清楚投哪类）

| 岗位类 | 核心工作 | 主语言 | 偏研究还是工程 |
|--------|---------|--------|--------------|
| **Autopilot AI / Neural Networks** | 感知/预测/规划的网络设计与训练 | Python(PyTorch) | 研究+工程 |
| **Autonomy Software** | 把模型落到车端、实时系统、后处理 | **C++** | 重工程 |
| **AI Infrastructure** | 数据管线、训练平台、Dojo | Python/C++/CUDA | 工程 |
| **Simulation** | 仿真环境、场景生成、闭环测试 | C++/Python | 工程 |
| **Data / Auto-labeling** | 自动标注、数据闭环、重建 | Python | 算法+工程 |

> 对深度学习背景的硕士，最对口的是 **Autopilot AI（感知方向）** 和 **Data/Auto-labeling**。但要知道：这两类也几乎都要求你能读写 C++（车端代码），纯 Python 很难过。

## 三、硬性条件（招聘要求拆解）

综合特斯拉及同类公司的 JD，感知/AI 岗常见门槛：

### 3.1 学历
- **BS/MS/PhD**，CS / EE / 机器人 / 应用数学等。
- 特斯拉不硬卡 PhD，但顶尖岗位竞争者多是 PhD 或有强工程履历的 MS。**MS + 亮眼作品/竞赛/开源**是现实可行的组合。

### 3.2 编程（最容易被低估的一关）
- **Python**：熟练，PyTorch 生态。
- **C++**：**生产级、现代 C++（C++14/17）**。自动驾驶车端是实时系统，C++ 几乎必备。很多 DL 背景的候选人挂在这里——一定要补。
- 数据结构与算法：**LeetCode 中等偏上**（特斯拉有真实 coding 面试）。
- 加分：CUDA、TensorRT、多线程、性能优化。

### 3.3 数学基础
- 线性代数（矩阵/SVD/最小二乘）、概率统计、最优化。
- **多视角几何 / 相机模型**（内外参、投影、三角化、对极几何）——纯视觉自动驾驶的命根子，一定要扎实。

### 3.4 深度学习功底
- 熟悉 CNN / Transformer / 检测 / 分割 / 自监督全栈。
- 能**从零实现并训练**一个模型，而不只是调 API。
- 理解大规模训练（分布式、混合精度、数据并行）。

## 四、必读论文清单（按主题，从基础到前沿）

> 建议顺序：先补感知基础（你做检测课题其实已覆盖不少），再重点攻 **BEV → Occupancy → 端到端**这条自动驾驶专属主线。带 ⭐ 的是自动驾驶方向的"必读中的必读"。

### 4.1 视觉感知基础（多数你课题已学过）
- ResNet、EfficientNet、ViT、Swin —— backbone。
- **YOLO 系列 / FCOS / DETR** —— 检测（你已深入）。
- FPN / PANet —— 多尺度融合。
- 分割：FCN / DeepLab / Mask2Former（车道线、可行驶区域）。

### 4.2 BEV 感知（自动驾驶感知的核心范式）⭐⭐⭐
- ⭐ **Lift-Splat-Shoot (LSS)**, Philion & Fidler, ECCV 2020 —— BEV 的开山之作，"把 2D 特征抬升到 3D 再拍扁成 BEV"。**必读**。
- ⭐ **BEVFormer**, ECCV 2022 —— 用 Transformer + 时序做 BEV，业界标杆。
- **BEVDet / BEVDepth** —— 显式深度监督的 BEV。
- **BEVFusion** (MIT), 2022 —— 相机 + 激光雷达 BEV 融合（虽然特斯拉纯视觉，但概念要懂）。
- **PETR / PETRv2 / StreamPETR** —— 3D 位置编码 + 时序，另一条主流 BEV 路线。

### 4.3 Occupancy / 3D 占据（特斯拉主推，前沿热点）⭐⭐
- ⭐ **占据网络思想**：看特斯拉 AI Day 2022 的 Occupancy Network 讲解（论文形式不全，视频最权威）。
- **TPVFormer**, CVPR 2023 —— 三视图占据表示。
- **SurroundOcc / OccNet / VoxFormer** —— 环视占据预测。

### 4.4 在线高精地图 / 车道（去高精地图路线）
- **MapTR / MapTRv2** —— 在线矢量化建图，实时生成车道拓扑。
- **VectorMapNet** —— 矢量地图学习。

### 4.5 端到端自动驾驶（最前沿，FSD v12 的方向）⭐⭐⭐
- ⭐ **UniAD**, CVPR 2023 **最佳论文** —— 把感知/预测/规划统一进一个端到端网络。**必读**。
- **VAD / VADv2** —— 矢量化端到端驾驶，效率更高。
- **世界模型**：**GAIA-1**（Wayve）、**MILE**（Wayve）—— 用生成式世界模型学驾驶，特斯拉也在这个方向投入。

### 4.6 数据引擎 / 自监督（特斯拉护城河相关）
- 自监督：MoCo / SimCLR / **DINO / DINOv2** / MAE（你课题已接触部分）。
- NeRF / 3D 重建思想（自动标注用到多帧重建）。

### 4.7 规划与预测（若投 planning 方向）
- 学习式规划、轨迹预测（如 VectorNet、TNT、DenseTNT）。

> **读法建议**：不要泛读。挑 **LSS → BEVFormer → UniAD** 三篇精读到能复现的程度，胜过泛读三十篇。配合 AI Day 视频建立全局观。

## 十一、执行清单 A：C++ 从零到"生产级"（假设你已会 Python）

> 为什么单独展开：这是 DL 背景转自动驾驶**最大的、也最被低估的门槛**。车端是实时系统，C++ 几乎绕不开；而 Python 老手常在这里挂掉。好消息：你已有编程思维（变量/循环/函数/OOP），学 C++ 是"补语言 + 补底层概念"，不是从头学编程。

### 阶段 1：语法与"和 Python 的根本不同"（2-3 周）
先建立 C++ 和 Python 的心智模型差异，这比背语法重要：

| 概念 | Python | C++ | 你必须补的点 |
|------|--------|-----|------------|
| 类型 | 动态、运行时 | **静态、编译期** | 声明类型、编译才能运行 |
| 内存 | 自动 GC | **手动/RAII 管理** | 栈 vs 堆、谁分配谁释放 |
| 变量 | 名字绑对象 | **值语义为主** | 拷贝 vs 引用 vs 指针 |
| 编译 | 解释执行 | **编译 + 链接** | 头文件/源文件、编译模型 |

- 学：基本类型、`if/for/while`、函数、**指针与引用**（重点难点）、`struct`/`class`、头文件与源文件分离、编译链接过程。
- 练：把你写过的几个 Python 小脚本（如排序、简单数据处理）用 C++ 重写。

### 阶段 2：现代 C++（C++11/14/17，3-4 周）⭐ 面试真正看的
这是"能不能写生产代码"的分水岭，务必吃透：
- **智能指针**：`unique_ptr` / `shared_ptr`（替代裸 `new/delete`，RAII 核心）
- **移动语义**：`std::move`、右值引用（性能关键，面试高频）
- **STL 容器**：`vector` / `map` / `unordered_map` / `set`，及其复杂度
- **STL 算法**：`sort` / `find` / `transform` + **lambda 表达式**
- **RAII**：资源获取即初始化（C++ 内存/资源管理的灵魂）
- 模板基础：泛型函数与容器（能读懂即可，不用一上来写复杂模板）

### 阶段 3：工程实践（3-4 周）
从"能写单文件"到"能搞工程"：
- **CMake**：C++ 项目的构建标准（自动驾驶代码全用它）
- **多线程**：`std::thread` / `mutex` / 条件变量（实时系统必备）
- **调试工具**：`gdb`（断点调试）、`valgrind`（内存泄漏检测）
- **Eigen 库**：C++ 的线性代数库（相机投影、矩阵运算都用它，衔接多视角几何）
- 代码规范：读懂 Google C++ Style Guide

### 阶段 4：接入自动驾驶（持续）
把 C++ 用到领域里：
- **libtorch**（PyTorch 的 C++ 前端）或 **ONNX Runtime C++ API**：把训练好的模型用 C++ 推理
- **ROS2 基础**：机器人/自动驾驶的通信中间件
- **读一份真实代码**：翻 **Autoware**（开源自动驾驶全栈，C++）或 **openpilot** 的部分模块，能读懂就是巨大进步

### 资源（精选，别贪多）

## 十二、执行清单 B：nuScenes BEV 感知项目从零起步

> 为什么选它：**nuScenes + BEV** 是自动驾驶感知最主流的组合，做通一个能直接当求职作品。你已有检测基础，这是"把 2D 检测能力升级到 3D/BEV"的最短路径。

### 前置准备
- **硬件**：至少一块 ≥12GB 显存的 GPU（BEV 训练吃显存，3090/4090 更稳；你实验室的 3090 够用）。
- **知识**：先精读 **LSS**（懂"2D 特征怎么抬到 BEV"）+ **BEVFormer**（懂 Transformer BEV），否则跑通了也不懂原理。
- **框架**：**mmdetection3d**（OpenMMLab 的 3D 检测库，集成了主流 BEV 方法，是最快上手路径）。

### 步骤 1：环境与数据（约 1 周）
- 装 **nuscenes-devkit** + **mmdetection3d**（跟官方安装文档，注意 CUDA/PyTorch 版本匹配，这步最容易踩坑）。
- 下载 nuScenes：先用 **mini 版**（约 4GB，10 个场景）跑通全流程，再上 **trainval 全量**（约 300GB+，要预留硬盘）。
- 理解数据结构：多相机图像、激光雷达点云、标注框、坐标系（ego / global / camera）、内外参。

### 步骤 2：跑通一个 baseline（约 1-2 周）
- 用 mmdetection3d 里现成的 **BEVFusion / BEVDet / BEVFormer** 配置，先在 mini 上跑通训练→评测。
- 目标：拿到评测指标 **mAP** 和 **NDS**（nuScenes Detection Score，官方综合指标），能复现官方数字（哪怕近似）。
- 这一步的价值：证明你能把一个复杂 3D 感知 pipeline 从数据到指标端到端跑通。

### 步骤 3：读懂代码（约 2 周）
不要停在"会跑"，要能讲清三件事（面试会问）：
1. **数据管线**：多相机图像怎么预处理、内外参怎么进网络。
2. **BEV 变换**：2D 特征**怎么变成 BEV 特征**（LSS 的 lift-splat，或 BEVFormer 的 spatial cross-attention）——这是核心中的核心。
3. **检测头**：BEV 特征上怎么出 3D 框（中心/尺寸/朝向/速度）。

### 步骤 4：做一点自己的改进（约 2-4 周）
有"自己的东西"才是作品，不是复现：
- 消融实验：改 BEV 分辨率 / 相机数量 / backbone，看指标变化，做成表格。
- 小改进：换个更强 backbone、加时序帧、调数据增强，哪怕只涨零点几个 NDS 也是你的贡献。
- 记录：每个实验的设置和结果，像写论文一样。

### 步骤 5：包装成作品（约 1 周）
- **GitHub 仓库**：清晰 README（做了什么、怎么复现、结果表、可视化图）。
- **技术博客**：写一篇"我如何在 nuScenes 上做 BEV 3D 检测"，讲清原理 + 踩坑 + 结果。
- **可视化**：BEV 俯视图 + 3D 框投影回图像的效果图（招聘方最爱看这个）。

### 常见坑（提前知道少踩）
- 环境安装：CUDA / PyTorch / mmcv 版本地狱，严格按官方版本表来。
- 显存爆炸：BEV 训练显存需求高，先降 batch / 用 mini / 用小分辨率。
- 训练时间：全量 nuScenes 训一个 BEV 模型可能要几天，先在 mini 上验证流程再上全量。
- 只会跑不懂原理：一定回头把 LSS 的 lift-splat 数学过程手推一遍。

### 里程碑自测
- [ ] 能在 nuScenes mini 上跑通 BEV 检测训练→评测，报出 mAP/NDS
- [ ] 能讲清 2D 特征→BEV 特征的变换机制（LSS 或 BEVFormer）
- [ ] 做了至少一组消融/改进实验，有结果表
- [ ] GitHub + 博客成型，有可视化效果图

> **时间预算**：集中投入约 **2-3 个月**出一个像样的作品。这一个项目 + 一份 openpilot PR，简历的自动驾驶含金量就立起来了。

## 十三、两份清单怎么并行

C++（清单 A）和 BEV 项目（清单 B）可以**交错推进**，不必串行：
- **前 1 个月**：C++ 阶段 1-2 打底 + 精读 LSS/BEVFormer + 装环境跑 nuScenes mini。

- **第 4-5 个月**：C++ 阶段 4（libtorch 推理，正好和 BEV 项目结合——把训练好的 BEV 模型用 C++ 部署！）+ BEV 做改进、包装作品。

> 最后这个结合点很妙：**用 C++ 把你自己的 BEV 模型部署起来**，一个项目同时证明了算法能力 + 工程能力，是最强的求职信号。

## 十四、聚焦：小鹏（XPeng）自动驾驶岗位要求

> ⚠️ 以下基于公开信息（截至约 2024-2025），具体以官网最新 JD 为准。小鹏是国内自动驾驶里**路线最接近特斯拉**的公司之一，这也是为什么前面第九节把它列为"技术栈重合、更现实的第一落点"。前面的准备清单（论文/C++/BEV 项目）**几乎原样适用**，这里只补小鹏的特点和侧重。

### 14.1 为什么小鹏值得重点看
- **技术激进、路线像特斯拉**：BEV + Occupancy + 端到端大模型 + 去高精地图，几乎是"中国版 Tesla FSD 路线"。
- **对国内硕士友好**：校招/社招/实习渠道齐全，不像特斯拉有签证/relocation 门槛。
- **你已有的基础对口**：检测/BEV/自监督那套直接能用。

### 14.2 小鹏的技术栈（面试前必懂）
| 模块 | 小鹏的东西 | 对标特斯拉 |
|------|-----------|-----------|
| 整体系统 | **XNGP**（全场景智能辅助驾驶，前身 XPILOT） | FSD |
| BEV 感知 | **XNet**（深度视觉感知网络，BEV + 动态/静态 + Occupancy）2.0 已上占据网络 | Tesla BEV + Occupancy |
| 规控 | **XPlanner**（神经网络规划器） | FSD Planner |
| 大模型 | **XBrain**（引入大语言模型做场景理解）、**端到端大模型**（XNet+XPlanner+XBrain 串起来） | FSD v12 端到端 |
| 云端算力 | **扶摇智算中心**（自建大规模训练集群） | Dojo |
| 自研芯片 | **图灵芯片**（自研 AI 推理芯片，2024 发布） | FSD 芯片 |
| 地图路线 | **去高精地图**、走"有导航就能开" | Tesla 无高精地图 |

> 一句话：小鹏这几年从"有图 + 激光雷达"快速转向"重感知、轻地图、端到端、大模型"，方向和特斯拉高度一致（区别：部分车型仍带激光雷达，做视觉+激光融合，不像特斯拉纯视觉）。

### 14.3 岗位方向（和大多数国内自动驾驶公司通用）
| 方向 | 核心工作 |
|------|---------|
| **感知算法** | BEV / Occupancy / 2D-3D 检测 / 分割 / 多传感器（视觉+激光+毫米波）融合 |
| **预测 & 规控** | 轨迹预测、行为决策、运动规划（XPlanner 相关） |
| **定位 & 建图** | 视觉/多传感器 SLAM、去高精地图的实时局部建图 |
| **数据闭环** | 自动标注、难例挖掘、数据管线（小鹏很重视，对标特斯拉 Data Engine） |
| **部署 / 嵌入式** | 模型量化剪枝、车端推理优化、芯片适配（图灵芯片相关） |
| **仿真** | 场景生成、闭环仿真测试 |
| **大模型** | 自动驾驶基础模型、世界模型、VLM 用于场景理解（XBrain 相关，和你 CLIP/VLM 背景最搭！） |

### 14.4 硬性要求
**校招（应届硕/博）**：
- 学历：硕士/博士为主（算法岗），CS/EE/自动化/机器人等；本科顶尖 + 强项目也有机会。
- 基础：扎实的深度学习 + 数据结构算法 + **Python 熟练、C++ 会用**。
- 加分：**竞赛名次 / 论文 / 有分量的项目**（nuScenes/Waymo 刷榜、开源贡献）。
- 面试：coding（LeetCode 中等）+ 深度学习基础 + 方向知识（BEV/检测/几何）+ 项目深挖。

**社招（有经验）**：
- 直接看**落地经验**：做过量产/接近量产的感知/规控项目，有 C++ 生产代码经验。
- 熟悉车端部署、实时系统、传感器标定与融合。

### 14.5 和特斯拉清单的差异（针对小鹏的侧重）
你前面准备的东西 90% 通用，针对小鹏额外注意三点：
1. **激光雷达/点云**：小鹏部分车型有激光雷达，感知岗可能涉及**点云处理 + 视觉激光融合**。补一点：PointNet/PointPillars/CenterPoint、BEVFusion（视觉+激光 BEV 融合）。特斯拉纯视觉不太碰这块。
2. **中文表达 + 国内生态**：中文简历/面试，了解国内自动驾驶落地的法规/场景（城市 NOA、泊车等）。
3. **你的 VLM 背景是差异化优势**：小鹏 XBrain 用大模型做场景理解，你课题里的 **CLIP / 视觉语言模型**经验正好对口"大模型 + 自动驾驶"这个最新方向——面试时这是你区别于纯 CV 候选人的亮点，值得主动讲。

### 14.6 针对小鹏的最小准备增量
在第十节那 5 件事基础上，冲小鹏再加 3 件：
1. 读懂小鹏公开的技术分享（XNet / XNGP / 端到端大模型的官方演讲、技术博客、发布会技术部分）——面试"你了解我们吗"直接用。
2. 补**点云 + 视觉激光融合**（PointPillars → BEVFusion），应对可能的激光雷达岗。
3. 把你的 **VLM/CLIP 经验往"大模型做场景理解"上靠**，准备一段能讲清"VLM 怎么帮自动驾驶理解长尾场景"的说辞。

### 14.7 投递渠道
- **校招**：小鹏官网招聘 / 秋招春招，实习转正是重要入口（强烈建议先争取**算法实习**）。
- **社招**：官网、脉脉、Boss 直聘、内推（内推命中率最高，多认识行业里的人）。
- **实习优先**：对在校生，一段小鹏（或任一头部自动驾驶公司）的**算法实习**，比任何证书都值钱，也是转正/背书的最短路径。

> **一句话策略**：小鹏 = 特斯拉的技术路线 + 国内可达的门槛 + 对你 VLM 背景友好的大模型方向。把它作为**现实首选目标**，准备内容和冲特斯拉 95% 重合，额外补点云融合 + 突出你的 VLM 差异化，再抓一段算法实习，就是很有竞争力的候选人了。
