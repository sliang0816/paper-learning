## v4 到 v5 的关键修正

1. 将“P2+CBAM 协同改进”改为“固定头宽 P2 受控配置效应”，避免忽略负交互和头宽混杂。
2. 删除无可靠依据的 OOD AUC、合成增强、已完成 ONNX/TensorRT 部署等表述。
3. 将“统计显著”“验证泛化”改为与证据规模相符的“方向一致”和局限性说明。
4. 加入 Grounding DINO/YOLO-World、6/8 类零样本协议、近重复隔离、CLIP 证据链和错误分解。
5. 软著、EI/SCI 加分和未实施的部署改为未来工作，不再当作已有成果。
