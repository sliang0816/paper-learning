# 开题答辩 PPT（2026-08-30）

本目录保存 25 页开题答辩成稿、PDF 预览、逐页讲稿和可复现构建脚本。

准备汇报时先读 [整体脉络](../../论文与实验思路梳理_20260822.md)，再打开本目录的 PPT/PDF 和讲稿。其余材料的开题相关性见 [项目入口](../../../README.md)。构建脚本与审阅记录属于制作支撑，日常排练无需阅读。

## 文件

- `朱守亮-开题答辩v8-开题版.pptx`：可编辑 PowerPoint 成稿。
- `朱守亮-开题答辩v8-开题版.pdf`：固定版式预览。
- `朱守亮-开题答辩v8-讲稿.md`：25 页逐页演讲备注。
- `build_开题答辩.py`：DeckKit 构建脚本。
- `style.py`：色彩与字体定义。
- `assets/`：用户提供的 v7 模板、校园图、校标和 Lucide 图标。
- `audit/`：首轮内容/设计审阅、渲染 lint、视觉合同和交付门禁证据；不是日常编辑入口。

论文源图复用 `paper/figures/` 中的文件，不在本目录重复保存。
历史 v3–v6 已归档到 `../archive/开题答辩旧版本/`；v7 重复件只保留为 `assets/template/江苏大学开题模板_v7.pptx`。

## 重建

从项目根目录运行：

```bash
python3 paper/ppt/开题答辩_20260830/build_开题答辩.py
```

成稿采用静态播放，无逐项动画。封面未显示未知导师姓名和精确答辩日期；确认信息后再补入。
