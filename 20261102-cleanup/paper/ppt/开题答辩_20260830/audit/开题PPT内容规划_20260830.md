## Comprehension brief

- **source size:** 主论文 PDF 58 页，约 20,695 load-words / 27,593 tokens；连同 v7 旧稿和 4 份辅助材料，约 30,066 load-words / 40,088 tokens。按 Long-source mode 处理。
- **一句话信息：** 本课题以固定头宽受控消融和 detector→CLIP 三级证据协议为两条主线，既验证 P2 在当前小目标数据上的可重复收益，也明确 CLIP 级联与跨域验证的能力边界，并据此规划后续确认性验证。
- **来源原句：** “固定分类头宽度后，P2在当前数据和训练协议下呈现跨5 seed一致的检测收益；CBAM没有稳定独立收益，且没有正向协同证据。”（`results/head_width_control_summary_5seed.md:21`）；“当前CLIP工作的主要价值是分层评估、失败分解和能力边界，而不是提出新基础模型或证明系统可部署。”（论文 PDF 第43–44页和第49页的结论归纳）。
- **贡献 1：** 用固定 128 分类头宽的 P2×CBAM 2×2 因子设计和 5-seed 同 seed 配对，消除原 P2 配置中头宽 128→64 的混杂，获得可归因的 P2 配置效应。（论文 PDF 第23–30页；`results/head_width_control_summary_5seed.md`）
- **贡献 2：** 将预留类别评估拆成真值框参考、端到端级联、验证集冻结校准三层，并把候选漏检、语义混淆、冗余候选和阈值过滤分别量化。（论文 PDF 第31–44页；表4.3、4.7、5.4）
- **贡献 3：** 用 RAOD、640 输入的 YOLO-World/Grounding DINO 和完整管线测速主动检验外部边界，不把局部正向结果写成普遍提升。（论文 PDF 第28、38–43、45–49页；结构化结果文件）
- **方法本质：** 第一阶段由 YOLOv8s/P2 生成候选框，第二阶段由 CLIP 在固定八类词表内命名；OOD 代理分数为 `s_ood(x) = -max_{c∈known} sim(x,c)`。该分数只作诊断与阈值组合，不是独立可靠拒识器。（论文 PDF 第31–34、41–43页）
- **作者强调一致性：** 论文第3章强调 P2 的受控收益与 CBAM/RAOD 边界，第4–5章强调分层协议、失败分解和不可过度外推；本规划没有把模块拼接、开放世界能力或部署成熟度抬高为论文主张。
- **关键限制原意：** test 曾被早期 prompt 探索查看；回溯内部确认不是从项目开始完全未查看的新数据；RAOD 未复现 AP50-95 提升；跨帧和目标边缘设备仍未完成。（论文 PDF 第32–33、38、41–44、48–52页；终审报告 §3、§6）

固定监控场景把小目标和预留类别命名同时变成瓶颈。现有方法缺少能区分结构收益、语义能力和系统误差的受控证据。因此本课题用两条主线回答“能否检测”和“能否命名”。近重复隔离和冻结协议让每个结论都有明确适用范围。P2 用更高分辨率特征保留小目标信息，但必须先消除分类头变窄的混杂。固定128头宽、5-seed配对表明P2在自建域重复获得收益，而CBAM没有稳定独立贡献。RAOD没有复现综合定位提升，说明收益存在域边界。CLIP只在固定词表内处理预留类别，并通过三级证据逐层加入真实误差。失败分解显示检测漏检、语义混淆和冗余候选共同限制端到端表现。直接开放词汇基线和效率测试进一步限定当前方案的相对位置与计算代价。创新不在模块命名，而在可归因实验、分层诊断和边界验证。后续工作将用真正独立确认、跨帧和目标设备测试完成闭环。

`spine verdict:` 正向阅读形成一条“问题→控制→证据→边界→计划”的论证；反向检查时，每页问题均由前一页结论引出或位于结构页之后。
