# 江苏大学硕士学位论文格式要求

> 提取自专业型硕士模板.doc 文本框注释及正文说明

## 一、封面与题名页

| 位置 | 字体 | 字号 | 对齐 |
|------|------|------|:--:|
| "硕士学位论文" | 华文中宋 | 33号 | 居中 |
| 中文论文题目 | 黑体 | 小二 | 居中 |
| 英文论文题目 | Times New Roman | 四号，大写 | 居中 |
| 作者/导师/专业信息 | 黑体+Times New Roman | 小三 | 居中 |

## 二、正文格式

| 元素 | 字体 | 字号 |
|------|------|------|
| 章标题（如"第一章 绪论"） | 黑体 | 15pt（小三） |
| 节标题（如"1.1 xxx"） | 黑体 | 14pt（四号） |
| 小节标题（如"1.1.1 xxx"） | 黑体 | 12pt（小四） |
| 正文 | 宋体 | 12pt（小四） |
| 英文/数字 | Times New Roman | 12pt |
| 图题/表题 | 黑体 | 10.5pt（五号） |
| 图注/表注 | 楷体 | 10.5pt（五号） |

## 三、图的要求

- 图号格式："图X.Y"（X=章号，Y=图序号），如"图3.1"
- 图题及说明用中文，图中标注用英文
- 图应具有"自明性"
- 曲线图坐标须标注"量、符号、单位"

## 四、表的要求

- 表号格式："表X.Y"，与图同理
- 表应有"自明性"
- 表内不宜用"同上""同左"等词
- 注释用"（注：……）"，五号楷体

## 五、参考文献

- 正文引用用**上标**标注［序号］
- 按引用顺序排列，不得分章放置
- 作者≤3位全列，>3位列前3位后加"等"或"et al."
- 格式符合 GB/T7714-2005

## 六、页眉页码

- 页眉：五号宋体居中
  - 奇数页："江苏大学硕士学位论文"
  - 偶数页：论文题目
- 页码：页脚外侧
  - 中文摘要～注释表：大写罗马数字（I, II, III...）
  - 绪论～附录：阿拉伯数字（1, 2, 3...）

## 七、论文顺序

中文题名页 → 英文题名页 → 独创性声明 → 版权使用授权书 → 中文摘要 → 英文摘要 → 目录 → 图表清单（必要时）→ 注释表（必要时）→ 绪论 → 正文 → 结论 → 参考文献 → 致谢 → 科研成果 → 附录（必要时）
