基于视觉语言模型的路面抛洒物检测方法研究

（一）研究目的与意义

路面抛洒物具有尺度小、低对比度、形态多变和类别开放等特点。固定监控摄像头能够持续覆盖高速公路路段，但对远距离小目标、复杂光照和未知类别的识别仍存在困难。本研究面向固定监控视频，构建“检测定位 + 开放词汇命名”的路面抛洒物识别方法。

本研究的两个核心研究点为：

1. 基于 YOLOv8s 的小目标检测改进：引入 P2/4 浅层检测尺度，并评估 CBAM 注意力模块对小目标检测的独立贡献；
2. 基于 CLIP 的开放词汇识别：将检测框图像与文本模板映射到共同语义空间，对未参与检测器训练的 GL（玻璃）和 RU（橡胶）进行零样本分类。

其中，P2 与 CBAM 属于检测结构改进，CLIP 开放类识别是主要学术研究方向。所有性能结论以修正后的数据和正式实验结果为准，不预设模块一定提升。

（二）相关研究概况

目标检测方面，YOLOv8 具有 anchor-free、解耦检测头和多尺度特征融合等特点，适合作为本项目统一基线。FPN/PAN 提供多尺度表示，P2 分支针对小目标保留更高空间分辨率，CBAM用于建模通道与空间注意力。

视觉语言方面，CLIP通过大规模图文对比学习建立图像与文本的共同嵌入空间，可在不使用目标类别下游训练样本的情况下进行零样本分类。Grounding DINO等开放词汇检测方法作为相关工作对照，但本项目优先采用“检测器候选框 + CLIP语义命名”的轻量两阶段方案。

（三）总体方法

系统流程为：

固定监控视频帧 → YOLOv8s候选框检测 → 检测框裁剪与适度外扩 → CLIP图像编码 → 与八类文本模板计算相似度 → 输出检测类别、开放词汇标签和异常分数。

YOLO训练使用六类已知类别：PL、ME、ST、VP、TD、OT；GL、RU不参与YOLO监督训练，仅用于零样本评估。开放词汇命名时与八类文本比较；OOD打分时只计算到六个已知类文本的最大相似度，避免将零样本类别纳入“已知度”计算。

（四）主要研究内容

1. 小目标检测改进

以 YOLOv8s 为统一基线，设置以下结构变体：

* baseline：原始 YOLOv8s；
* p2_cbam：P2 浅层检测尺度 + CBAM；
* p2_only：仅增加 P2；
* cbam_only：仅增加 CBAM。

通过统一数据、输入尺寸、训练轮数、随机种子和评估流程，分析 P2 与 CBAM 的独立及联合贡献。重点报告 mAP@0.5、mAP@0.5:0.95、Precision、Recall、各类别 AP、参数量和推理延迟。

2. CLIP开放类识别

对检测框图像进行裁剪和外扩，使用多个英文文本模板构建八类文本嵌入，并计算图文余弦相似度。EXP-003a使用真实标注框测量CLIP分类上界；EXP-003b使用检测器预测框测量完整链路，并分解检测漏检和CLIP误分类造成的性能损失。

3. OOD辅助评分

OOD不作为独立检测头的既定结构，而作为辅助分析模块。当前实现使用检测框图像与六个已知类文本的最大相似度构造分数，并使用ROC-AUC评价已知类与零样本类的排序区分能力。阈值和最终分数必须由验证集校准，测试集只用于最终报告。

4. 数据增强辅助实验

当前数据集内实例较少的类别为 GL、RU、ST。由于GL/RU承担零样本留出任务，不能把它们的合成图加入主YOLO训练。若开展ControlNet增强，优先从ST开始，并单独报告合成比例、数据来源、人工质量筛选和对真实测试集的影响。数据增强不作为本项目主要创新点。

（五）数据集与实验环境

数据来自两批固定监控视频标注批次，原始视频约2TB。原图共4878张，其中4651张有LabelMe JSON并进入正式数据，共6108个八类真值框；剔除GL/RU后的六类视图共5727个框。01/02仅代表两位标注者，不代表不同来源域。

正式数据先将dHash汉明距离不超过2的近重复帧组成不可拆分组，再平衡类别和标注批次，八类基础划分为训练3251张、验证700张、独立测试700张。六类检测训练集进一步排除230张含GL/RU的图片，最终使用3021张和4032个已知类框，避免把零样本留出类当作背景监督。三个集合之间精确重复和该阈值下近重复均为0；测试集不参与训练、早停和调参。因缺少原始视频片段ID，本文不声称跨摄像头或跨场景泛化。

正式实验环境：Ubuntu 22.04、Python 3.10.19、PyTorch 2.7.1+cu118、CUDA可用、Ultralytics 8.3.234、Transformers 5.9.0、scikit-learn 1.7.2、RTX 3090 24GB。环境固定在 `vlm-rd-detect` conda 环境中。

（六）实验安排

| 实验 | 内容 | 目的 |
|---|---|---|
| EXP-001 | YOLOv8s baseline | 建立六类检测基线 |
| EXP-002 | P2 + CBAM | 验证联合改进效果 |
| EXP-004a | 仅P2 | 分离P2贡献 |
| EXP-004b | 仅CBAM | 分离CBAM贡献 |
| EXP-003a | GT框 + CLIP | 测量零样本分类上界 |
| EXP-003b | YOLO框 + CLIP | 测量完整端到端效果 |

关键指标包括：已知类检测 mAP、Recall、各类AP、GL/RU零样本 top-1、OOD AUC、检测召回率、CLIP分类准确率、FPS和延迟。不得将历史错误标签上的 EXP-001/002/003 结果作为正式结论。

（七）预期成果

1. 形成面向固定监控视角的路面抛洒物检测数据和处理流程；
2. 完成YOLOv8s小目标检测结构的对比与消融分析；
3. 完成检测框与CLIP结合的开放词汇识别验证；
4. 完成ONNX导出和基础推理延迟测试（如环境支持）；
5. 形成硕士学位论文、软件著作权等成果材料。

论文不预先承诺固定的mAP或AUC数值。最终结论根据独立测试集、多随机种子实验和消融结果确定；若某一结构没有提升，也应分析其与目标尺寸、背景和数据分布的关系。

（八）研究范围说明

当前主线只研究固定监控视角。无人机采集、跨视角泛化、Jetson部署、在线跟踪预警和大规模扩散数据增强均属于可选后续工作，只有在实际完成相应数据和实验后才能写入论文成果。
