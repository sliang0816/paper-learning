# 路面抛洒物检测课题历史资料

这里保存从原课题迁出的文稿、制度、脚本和工具材料；持续维护的论文解析与学习练习已移至根目录 [learning/](../../learning/README.md)。

| 目录 | 用途 |
|---|---|
| [docs/](docs/) | 原课题格式要求、评估指标、培养制度与参考材料 |
| [paper/ppt/](paper/ppt/) | 历史答辩演示稿、构建源文件、配图、渲染与审计材料 |
| [paper/word/](paper/word/) | 旧 Word 文稿 |
| [scripts/](scripts/) | 原项目实验队列、定时调度、构建和转换脚本 |
| `.agents/`、`skills-lock.json` | 当时使用的工具技能快照 |
| `.deck-work/`、`.codex-backups/` | 历史演示稿工作材料与工具备份 |

这些材料保留原课题上下文，内部的旧路径、实验状态与机器配置不保证仍然有效。需要继续正式实验时，应回到独立的 `vlm-rd-detect` 项目确认当前入口和依赖。这里的技能快照也不代表本项目启用的技能。

迁移来源与目录对应关系见[迁移记录](../../docs/迁移记录.md)。
