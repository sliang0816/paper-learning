## 一、史前时代：从感知机到反向传播（1943—1990s）

| 年份 | 里程碑 | 意义 |
|------|--------|------|
| 1943 | McCulloch & Pitts 神经元模型 | 首个数学化神经元 |
| 1958 | Rosenblatt 感知机（Perceptron） | 第一个可训练的单层网络 |
| 1969 | Minsky & Papert《感知机》 | 指出线性不可分局限，AI 第一次寒冬 |
| 1986 | Rumelhart 等人反向传播算法（BP） | 多层网络训练成为可能 |
| 1989 | LeCun 等人将 BP 用于手写数字识别 | CNN 雏形，后演变为 LeNet |
| 1997 | LSTM（Hochreiter & Schmidhuber） | 解决 RNN 长程依赖问题 |

**为什么 1990s 又沉寂？** 数据量不足 + 计算力不够 + 梯度消失问题未彻底解决。

## 二、卷积神经网络崛起（1998—2014）

### 2.1 LeNet-5（1998，LeCun）

- 结构：Conv → Pool → Conv → Pool → FC
- 用于邮政编码识别，证明 CNN 对图像有效
- 局限：数据量小，无法推广到复杂场景

### 2.2 AlexNet（2012，Krizhevsky）—— 深度学习元年

```
ImageNet 2012：Top-5 错误率 15.3%（第二名 26.2%）
```

核心贡献：
- **ReLU** 激活函数：解决梯度消失，加速收敛
- **Dropout**：防止过拟合
- **GPU 并行训练**：两块 GTX 580 分布式训练
- **数据增强**：翻转、裁剪、色彩抖动

> AlexNet 的意义不仅是赢得比赛，而是证明了"大数据 + 大算力 + 深网络"这一范式的可行性。

### 2.3 VGGNet（2014，Simonyan & Zisserman）

核心思想：**用 3×3 小卷积核堆叠替代大卷积核**

- 两个 3×3 感受野 = 一个 5×5，但参数少、非线性多
- VGG-16 / VGG-19：16/19 层
- 结构简洁统一，至今仍是特征提取骨干

### 2.4 GoogLeNet / Inception（2014，Szegedy）

核心思想：**Inception 模块——并行多尺度卷积**

```
同一层并行：1×1 + 3×3 + 5×5 + MaxPool → 拼接
```

- 引入 **1×1 卷积**做通道降维（计算效率革命）
- 22 层但参数量仅 AlexNet 的 1/12

### 2.5 ResNet（2015，He Kaiming）—— 现代 CNN 基石

```
ImageNet 2015：Top-5 错误率 3.57%，超越人类（5.1%）
```

核心创新：**残差连接（Skip Connection）**

```
输出 = F(x) + x
```

意义：
- 解决**梯度消失/爆炸**，网络可深达 152 层
- 残差学习更容易优化（学习"残差"而非直接映射）
- ResNet-50/101/152 成为此后十年最常用骨干

**后续变体**：ResNeXt、WideResNet、SE-Net（通道注意力）

## 三、目标检测主线（2014—至今）

### 3.1 两阶段检测器（Two-Stage）

#### R-CNN（2014，Girshick）
```
候选区域（Selective Search） → CNN 特征提取 → SVM 分类 → 回归框
```
问题：每个候选框单独过 CNN，极慢（~47 秒/张）

#### Fast R-CNN（2015）
```
整图过 CNN → RoI Pooling 从特征图裁剪 → 分类 + 回归
```
提速 9× ，但候选框生成仍是瓶颈

#### Faster R-CNN（2015，Ren）—— 两阶段检测器标杆
```
整图过 CNN → RPN 生成候选框 → RoI Pooling → 检测头
```
- **RPN（Region Proposal Network）**：用神经网络替代 Selective Search
- 端到端训练，5 fps
- Anchor 机制：预设多尺度多比例锚点

#### FPN（2017，Lin）—— 多尺度特征金字塔
```
骨干特征图（C2~C5） → 自顶向下融合 → P2~P5 多尺度输出
```
- 低层特征细节丰富（小目标），高层特征语义丰富
- 成为现代检测器标配，YOLOv8 的 PANet 即其演进

### 3.2 单阶段检测器（One-Stage）

#### YOLO v1（2016，Redmon）—— 实时检测开山之作
```
整图 → 单次前向传播 → 直接预测框 + 类别
```
- 将检测视为回归问题，45 fps（~155 fps 快速版）
- 缺点：小目标差，每格只预测 2 个框

#### SSD（2016，Liu）
- 多尺度特征图上预测（类似 FPN 思路）
- 比 YOLO v1 精度高，速度相当

#### YOLO 演进路线

| 版本 | 年份 | 核心改进 |
|------|------|---------|
| v2 | 2017 | Anchor + BatchNorm + 多尺度训练 |
| v3 | 2018 | 多尺度预测（3 个 FPN 层），Darknet-53 骨干 |
| v4 | 2020 | CSP 结构，Mosaic 增强，PANet 颈部 |
| v5 | 2020 | Ultralytics 重构，PyTorch 实现，工程化成熟 |
| v6/v7 | 2022 | 各自优化 anchor-free 与效率 |
| **v8** | **2023** | **anchor-free，解耦头，C2f 模块，本项目基线** |
| v9 | 2024 | GELAN + PGI，梯度信息保留 |
| v10 | 2024 | 无 NMS 设计 |
| v11 | 2024 | 更轻量骨干，本项目对比参考 |

#### DETR（2020，Carion）—— Transformer 进入检测
- 将检测视为集合预测问题，用 Transformer 编解码
- 无需 Anchor、无需 NMS
- 收敛慢，但开创了检测 Transformer 范式

#### Grounding DINO（2023）—— 开放词汇检测
- 融合 BERT 文本编码与 Swin Transformer 视觉编码
- 实现文本驱动的开放类目标检测
- 与本项目 CLIP 模块目标相近，可作相关工作对比

## 四、注意力机制与 Transformer（2017—至今）

### 4.1 Attention 机制（2015，Bahdanau）
- 原用于 NLP 机器翻译，让模型"聚焦"相关词
- 核心公式：$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$

### 4.2 Transformer（2017，Vaswani）—— "Attention is All You Need"

**Multi-Head Self-Attention + Position Encoding + FFN**

彻底替代 RNN，并行度高，成为 NLP 统治架构。

### 4.3 BERT（2018，Google）
- 双向 Transformer 预训练，掩码语言模型
- NLP 迁移学习范式确立

### 4.4 GPT 系列（2018—2023，OpenAI）
- 单向自回归生成，GPT-3（1750 亿参数）证明大模型涌现能力
- GPT-4 实现多模态理解
