## 一、方法：三条升级

1. **从"读"转向"写代码跑"**（最大缺口）
   - 读懂 100 篇 < 亲手实现 3 个。
   - 不是从零造轮子，而是**改跑真实代码**：给 YOLOv8 检测头、CLIP 的 forward 打断点、改几行看输出变化。
   - **手写 mini 版**：50 行 numpy/PyTorch 实现一个自注意力、一个 Conv+BN，写完对 Q/K/V、权重共享的理解会质变。
   - 让 **EXP-001~004 实验驱动**要深读什么。

2. **读论文用「三遍法」+ 带问题读**（别线性通读）
   - 第一遍(5 min)：标题/摘要/图/结论 → 判断要不要深读；
   - 第二遍(1 h)：读正文、跳过证明 → 抓方法主干；
   - 第三遍(要复现时)：逐公式对着代码读。
   - 读"能回答你此刻问题"的论文，不是清单式读完。

3. **深度 > 广度**
   - 广度够了（90+ 篇）。对毕业相关的 ~10 篇（YOLOv8、CLIP、FPN、CBAM、PatchCore、RetinaNet…）：读官方代码、能复现关键数字、能画图讲清。
   - 其余维持"知道是什么、放哪个位置"即可。

> 一句话：输入(读)+思考(问)已是优等生水平，缺的是**输出(写代码、跑实验、复现)**。跨过这一步，就从"懂很多"变"能做出来"——这正是论文和找工作真正要的。

## 四、白天手敲路线（允许短时 GPU，不运行长训练）

不要直接复制项目现有实现。每项先自己写，再与正式代码对照；单项控制在
30～60 分钟。项目已经建立独立的 [`learning/`](../learning/README.md) 学习区，
模板放在 `learning/exercises/`，不会接入正式实验入口。先运行：

```bash
python learning/check_progress.py
python learning/check_progress.py --exercise 1
```

全部完成后运行 `python learning/check_progress.py --strict` 做最终验收。

白天 GPU 使用边界：

- 可以：加载一次模型、单张或小批量推理、注册 hook 打印 shape、一次
  forward/backward、CUDA 与 CPU 输出对照；
- 不建议：完整 epoch、遍历 train/val/test、超参数搜索、多 seed 或重复测速；
- 每次调试结束及时退出 Python，确认 `nvidia-smi` 中不再残留进程。

### 1. IoU、匹配与 Precision/Recall（最优先）

手写函数：

```python
box_iou(box_a, box_b)
match_predictions(predictions, ground_truths, iou_threshold=0.5)
precision_recall(tp, fp, fn)
```

验收要求：

- 能解释一个预测框为什么是 TP、FP 或重复检测；
- 手算 3 个预测框、2 个真值框的 Precision 和 Recall；
- 修改 IoU 阈值后，能预测指标如何变化。

关联参考文档：[原课题实验评估指标说明](../archive/road-debris-detection/docs/实验评估指标说明.md)。

### 2. mini FPN/P2 特征融合

只创建随机张量，不加载 YOLO：

```text
P3: [1, C3, 80, 80]
P2: [1, C2, 160, 160]
P3 上采样 → 与 P2 concat → 卷积融合
```

验收要求：

- 打印上采样前后以及 concat 后的 shape；
- 能解释为什么 P2 对小目标保留更多空间细节；
- 能解释加入 P2 后 FLOPs 和延迟为何上升。

完成后再对照 `experiments/anomaly_head/yolov8s-p2.yaml`。

### 3. mini CBAM

用 PyTorch 手写：

```text
输入 x
→ 通道平均池化/最大池化
→ 共享 MLP + sigmoid
→ 通道加权
→ 通道维平均/最大池化
→ 7×7 卷积 + sigmoid
→ 空间加权
```

验收要求：

- 输入和输出 shape 完全一致；
- 通道权重形状为 `[B,C,1,1]`；
- 空间权重形状为 `[B,1,H,W]`；
- 与 `experiments/anomaly_head/cbam.py` 对照差异。

### 4. CLIP 相似度与 OOD 分数

先不用加载 CLIP，只对几组手写向量实现：

```python
l2_normalize(features)
cosine_logits(image_features, text_features)
ood_score = 1 - max_known_similarity
```

验收要求：

- 说明为什么图像和文本特征要 L2 归一化；
- 区分 top-1 分类正确率与 OOD AUC；
- 构造一个“分类错误但 OOD 排序正确”的例子。

理解数学过程后，再手写最小 CLIP demo；不要在正式 test 上反复试 prompt。

### 5. 多随机种子统计

手动读取四个 seed 0 的 `metrics.json`，先不用现成汇总脚本，实现：

```python
mean_std(values)
paired_delta(model, baseline)
interaction = joint - p2_only - cbam_only + baseline
```

验收要求：

- seed 0 上算出 mAP50 交互项 `+2.03` 个百分点；
- 解释为什么只有一个 seed 时不能报告有意义的标准差；
- 再与 `experiments/summarize_detection_results.py` 输出逐项核对。

### 6. 每次练习的输出模板

每项结束只记录四句话：

1. 输入和输出分别是什么；
2. 核心公式对应哪几行代码；
3. 最容易写错的 shape、阈值或统计口径是什么；
4. 它与当前论文哪一节、哪个实验直接相关。

这比继续无差别扩充模型阅读数量更优先。论文阅读仍需继续，但只围绕
路面异物、小目标、P2/注意力协同、CLIP/OOD 的当前证据缺口进行。
